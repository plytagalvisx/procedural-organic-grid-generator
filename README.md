# Procedural Organic Grid Generator

A Unity and C# procedural-generation project that creates islands on
irregular organic grids. The system combines custom mesh generation,
marching cubes and wave function collapse to place compatible structural
modules.

## Features

- Procedural irregular-grid generation
- Runtime mesh construction
- Marching-cubes-based geometry
- Wave-function-collapse module selection
- Configurable Unity assets and prefabs
